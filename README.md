# 🏍️ Bike Information Website

A modern and interactive **Bike Information Website** developed to provide users with information about different motorcycle companies and models.

The website allows users to explore bikes and view important specifications such as engine capacity, top speed, fuel tank capacity, mileage, gearbox, braking system, seating capacity, and price.

## ✨ Features

* 🏍️ Explore different motorcycle companies
* 🔍 Explore individual bike models
* 📊 View detailed bike specifications
* ⚡ Display engine capacity and top speed
* ⛽ View fuel tank capacity and mileage
* ⚙️ View gearbox and braking system details
* 💰 Display bike prices
* 🔐 Login page
* 📝 Sign Up page
* 📩 Contact Us page
* 🎬 Animated/video-based homepage
* ✨ Interactive animations and transitions

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Swiper.js

## 📚 Project Purpose

This project was created to practice and demonstrate **frontend web development**, including HTML structure, CSS styling, JavaScript interactions, animations, responsive layouts, and interactive UI components.
